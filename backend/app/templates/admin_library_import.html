Bulk reading import

Create or update many library readings from one Excel workbook. Validation runs before anything is written to PostgreSQL.

1. Prepare the workbook

Use the official LECTURAS sheet, or export the current library and edit it in bulk.

Download empty template Export current library
Supported fields: code, CEFR level, category, order, title, summary, full content, source, source URL and publication status. Word count is recalculated automatically.

2. Validate and preview

The preview identifies which readings will be created and which will be updated.

Maximum size: 10 MB. Existing codes are updated; new codes are created. Despublishing is safer than deleting readings already referenced by saved vocabulary.
